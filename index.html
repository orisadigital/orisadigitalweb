Our Work

Questions

Before You
Get in Touch

The things people ask us most, answered plainly. If yours is not here, send it over — we would rather answer it than have you guess.

  • How much does a website cost?

    A one page website starts at RM999 and an SME website at RM1,896. What moves the figure from there is the number of pages, the features you need, and add-ons like a blog, a booking form, or a payment gateway. The website pricing calculator adds it all up so you know the number before you get in touch.

  • How long does a project take?

    It depends on how much there is to build. Every project runs through the same six stages — research, wireframe, mockup, prototype, build, and handover — and you get a timeline with your quote, once we know the scope, rather than a guess before we do.

  • Do you work with businesses outside Kuching?

    Yes. We are based in Kuching and work with businesses across Sarawak and the rest of Malaysia. Most of a project runs over WhatsApp, email, and calls, so where you are rarely changes how it goes.

  • What is included in a website?

    Responsive design that holds up on phone, tablet, and desktop; UI/UX design and research; a content management system so you can edit your own pages afterwards; performance and security work; and a full handover once everything is tested and live. The web design page goes through it in detail.

  • Do you build web apps as well?

    Yes. We build cross-platform mobile and web applications for businesses that need to streamline operations or put something in their customers’ hands. See the web app page for how those are built.

  • What is green hosting, and does it matter?

    Every website runs on a server somewhere, and data centres account for roughly 2% of global carbon emissions. We host on providers running renewable power and build lean sites that move less data to begin with. The green energy page has the full picture.
